RC Tools へようこそ

RC Tools は wplace の道路敷設・地図反映作業を効率化するためのツール集です。
必要なツールを選んでご利用ください。

道路地図URL変換ツール

wplace道路地図のURLと現地のURLを相互に変換できます。

開く

URL座標変換ツール

wplace の URL の緯度・経度から世界座標、チャンク座標、タイル座標に変換できます。

開く

折れ線プランナー

始点と終点の座標から道路の折れ点を計算し、折れ線の作成が容易にできます。

開く

ペイント量計算ツール

2地点のURLから、xy方向の距離と必要なペイント量(px)を計算します。(傾きが1を跨ぐ道路には使用できません)

開く

完成予定日計算

2つの日付と残りペイント数から、完成予定日・進捗速度・人数換算を推定します。

開く
